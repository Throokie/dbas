## Frontend Development Instructions

1. Use functional components with hooks, not class components
2. Define TypeScript interfaces for all props
3. Use Tailwind CSS for styling
4. Implement error boundaries for async operations
5. Add loading states for all data-fetching components
6. Write unit tests for utility functions and complex components
7. Use React Query for server state management
