## Security Audit Instructions

When performing a security audit, follow these steps:

1. Scan all files for hardcoded secrets (API keys, passwords, tokens)
2. Check for SQL injection vulnerabilities in database queries
3. Verify input validation on all user-facing endpoints
4. Review dependency versions for known CVEs
5. Check authentication and authorization logic
